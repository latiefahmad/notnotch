A memory fix for copies that stay open for days.

## What changed

- **Hardware: the program-name cache is bounded.** The tool keeps the display name of each program it shows, because reading that name means opening the exe and parsing its version resource. The cache that held those names was never trimmed: it stored every program path ever listed, so a copy left running for days collected them without limit. Past 256 entries the cache now starts again, which costs one file read per program on screen and never grows.

## Under the hood

- `cached_name` in `src-tauri/src/system.rs` holds the lookup and the bound, with tests for the caching and for the cache staying bounded.
